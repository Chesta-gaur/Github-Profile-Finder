# Github-Profile-Finder
A responsive and interactive web application that allows users to search for any GitHub profile and instantly retrieve live data such as profile details, repositories, followers, and following count using the GitHub REST API.

# About the Project
The GitHub Profile Finder is a frontend-based project that integrates with the GitHub Users API to dynamically fetch and display user profile information.
It provides a real-time search experience — delivering a developer’s essential GitHub data in a clean, visually appealing card layout.

This project demonstrates proficiency in API integration, asynchronous JavaScript (async/await), and responsive web design.

# Features
✅ Real-time GitHub user search
✅ Displays profile image, username, bio, and stats (followers, following, repos)
✅ Fetches and displays latest 5 repositories
✅ Responsive and mobile-friendly design
✅ Error handling for invalid usernames
✅ Minimal UI inspired by GitHub’s theme
✅ Autocomplete disabled for clean input experience
